# Руководство пользователя

[Установка](../README.md#установка) · [Формат очереди](MARKDOWN.md)

## Обзор

Приложение содержит две очереди: «Университет» и «Саморазвитие». Они независимы. Название или кнопка «Выбрать» выбирают очередь для следующего занятия; синяя рамка обозначает выбор. Меню `⋯` у заголовка подключает ваш Markdown-файл.

Поле под очередью добавляет новую задачу **в начало** списка. После сохранения приложение показывает её сверху, даже если до этого был открыт дальний отрезок. Подпункт добавляется через меню родительской задачи; родитель раскрывается после добавления.

Подпункты в обзоре свёрнуты при запуске. Нажмите стрелку рядом с ручкой, чтобы раскрыть блок. Раскрытие сохраняется при обновлениях, фильтрации и переходах между группами во время текущего запуска. В рабочем режиме все подпункты показаны сразу.

Для редактирования нажмите на текст: **Enter** сохраняет, **Esc** возвращает прежний текст. Уход из поля тоже сохраняет ввод. При ошибке записи текст остаётся для исправления. Квадратик меняет выполнение. Меню `⋯` строки удаляет пункт; удаление родителя включает его подпункты.

Для перестановки тяните за ручку из трёх полосок. Полупрозрачный блок показывает место вставки, соседние блоки сдвигаются. В зоне около точки захвата прокрутка стоит; дальше вверх или вниз она ускоряется. Перестановка действует внутри показанного отрезка. **Esc** отменяет перетаскивание.

Обзор показывает 15 ближайших невыполненных задач. Выполнение освобождает место следующему пункту. Кнопки под очередью открывают остальные группы. «Показать выполненное» показывает до 15 предыдущих выполненных; «Ранее / Позже» позволяют просматривать более старые. Очень длинные подпункты в раскрытом обзоре имеют отдельные переходы.

## Плановое время

При запуске выбранная длительность равна нулю. Порядок элементов: **Сброс → +5 → +15 → +60 → выбранное время → Начать занятие**. Можно ввести время вручную; допустимы 1–480 минут.

`+60`, `+60`, `+15` дают 135 минут. «Сброс» позволяет набрать время заново. В узком окне подписи сокращаются, полные названия доступны в подсказках.

## Во время занятия

До запуска можно выбрать конкретную невыполненную задачу в обзоре: `⋯` → **«Выбрать для занятия»**. Её очередь активируется, весь блок выделяется синей рамкой и подписью «С неё начнётся занятие». Настройте время и нажмите «Начать занятие». Выбор сохраняется при переходах между отрезками обзора; снять его можно через `⋯` → «Сбросить выбор». Смена очереди сбрасывает точку старта. После успешного запуска выбор используется один раз; без выбора новое занятие начинается с первой невыполненной задачи.

Если выбранная задача удалена, выполнена или больше не определяется после внешних изменений, приложение сбрасывает выбор с сообщением. Запуск, обнаруживший такую ситуацию, останавливается, чтобы не открыть другую задачу без вашего решения.

Рабочая карточка показывает текущую задачу и все её подпункты. Содержимое прокручивается, заголовок и таймер остаются на месте. Нажатие на квадратик отмечает пункт; текст доступен для редактирования. «+ Задача» добавляет следующий корневой блок сразу после текущего, «+ Подпункт» добавляет действие к текущему родителю. Обе кнопки используют встроенный редактор; переключение сохраняет черновик.

| Действие | Результат |
| --- | --- |
| Отметить последний подпункт | Родитель также становится выполненным. |
| Завершить задачу и подпункты | Отметить весь блок, затем перейти дальше. |
| Снять отметку с родителя | Открыть родителя и все его подпункты. |
| Снять отметку с подпункта | Открыть его и родителя, сохранить остальные отметки. |
| Стрелка вперёд | Пропустить текущую задачу без выполнения. |
| Стрелка назад | Вернуться к предыдущему блоку, включая выполненный. |
| Пауза / Продолжить | Остановить / возобновить оба отсчёта. |
| +10 / +15 / +30 минут | Продлить план. |
| Завершить занятие | Сохранить фактическое время и открыть результаты. |

После выполнения приложение ищет следующую невыполненную задачу **только ниже текущей**. Это правило действует и при старте с выбранной задачи, и после пропуска стрелками. Если дальше задач нет, показывается конец очереди; пропущенные выше остаются невыполненными, вернуться к ним можно стрелкой назад. Таймер продолжает работать, пока вы не завершите занятие. Добавленная в конце из рабочего экрана новая задача становится текущей.

Ноль на таймере не завершает задачу: начинается учёт сверх плана. Раннее завершение занятия сохраняет только отработанное время. Пауза и закрытое приложение исключаются из учёта.

**Ctrl+Z** вне поля текста отменяет одно последнее выполнение текущего занятия. В редакторе он отменяет ввод. Редактирование, удаление, обновление очереди и ручное снятие отметок сбрасывают отмену выполнения. Это не отмена перестановки.

## Результаты

История показывает занятия, активное время и выполненные задачи / подпункты. Звёздочка сохраняет занятие в избранном; «Все / Избранные» фильтрует список. Общие итоги времени остаются общими.

Удаление занятия убирает его из истории и итогов. Оно не меняет Markdown-отметки и не отменяет выполнение задач. Правки текущего занятия согласуют его зачёт с состоянием очереди; ранее завершённые занятия сохраняются.

## Сохранение и восстановление

Профиль находится в `%LOCALAPPDATA%\StudyQueues` либо в выбранной папке `--data-dir`. Перед изменением Markdown создаётся резервная копия в `backups/`; приложение проверяет внешние изменения и заменяет файл атомарно. Успешная запись предшествует анимации завершения или перестановки.

После внешних правок нажмите `↻`. Если возник конфликт, приложение оставляет файл внешнего редактора и показывает сообщение. Работайте с очередью последовательно в приложении и редакторе.

Незавершённое занятие можно восстановить **на паузе** после повторного запуска. Снимок сохраняется после значимых действий и примерно каждые пять секунд; при аварии может потеряться последний несохранённый интервал.

Разрыв обновлений больше 10 секунд, например при сне компьютера или задержке процесса, ставит занятие на паузу и исключает неизвестный интервал. Обычное сворачивание не останавливает работу. Реальный сон Windows ещё требует проверки в обычном использовании.

Если приложение сообщает о повреждении данных, сохраните копию проблемного файла перед восстановлением. Оно не заменяет повреждённую историю пустой. Не удаляйте исходные Markdown-очереди.
